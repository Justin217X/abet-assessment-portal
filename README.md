# ABET Accreditation Automation Portal
A capstone project by Team 18, SWENG 480, Penn State Behrend

## Project Overview
The proposed portal will help Faculty and ABET coordinators prepare, review, 
and organize assessment reports with less repeated manual work.

It will support retrieving assessment information from Canvas, selecting
student evidence, preparing report packets, coordinating peer reviews, 
and maintaining historical assessment records.

Faculty remain responsible for academic judgements. Penn State remains responsible 
for preparing the complete Self-Study Report and submitting official accreditation
documents to ABET. 

## Current Status
The project is in the requirements and design stage. The report and diagrams 
are still being finalized. 

The documented features and performance targets describe the proposed system. 
They haver not yet been demonstrated through implementation and testing.

## Main Users
- Faculty: Prepare assessment reports and complete assigned peer reviews. 
- ABET Coordinator: Organize assessment work, monitor, progress, and record findings and improvement actions.
- ABET Evaluator: Review authorized assessment reports and supporting evidence. 
- System Administrator: Manage portal access, application settings, and technical issues.


## Main Features
- Retrieve permitted assignments, rubric, score, submission, and feedback information from Canvas. 
- Import CSV or Excel roster and confirm which students belong in an assessment. 
- Reuse mappings between assignments, rubric criteria, performance indicators, and student outcomes. 
- Suggest student evidence near the highest, middle, and lowest scores for faculty review. 
- Prepare Rubric Reports, PI Reports, and Final Instrument Report packets. 
- Save drafts, check missing materials, and preview reports.
- Support assessment assignments, peer review, and report revisions.
- Preserve earlier submitted report versions. 
- Restrict access according to assigned roles and permissions.
